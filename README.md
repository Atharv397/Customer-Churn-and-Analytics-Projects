# Customer Churn and Analytics Projects

## About the Repository
This repository contains three Data Analytics projects using Python. These projects focus on customer demographics, subscription and churn analysis, and customer support and satisfaction analysis.

## Projects

### 1. Customer Demographic and Segmentation Analysis
- Analyzed customer demographic information.
- Explored customer distribution by gender, country, and interests.
- Performed data cleaning and visualization.

### 2. Subscription and Churn Analysis
- Analyzed subscription types and plan types.
- Explored monthly charges and customer lifetime value (CLTV).
- Analyzed customer churn patterns and cancellation reasons.

### 3. Customer Support and Satisfaction Analysis
- Analyzed customer complaints and support data.
- Explored CSAT scores and escalations.
- Analyzed complaint trends and customer feedback.
